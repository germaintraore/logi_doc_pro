# Instructions Spécifiques Frontend (React)

## Directives
- Séparer la logique métier (hooks) des composants d'affichage (UI).
- Centraliser les appels API dans un dossier `src/services/`.
- Utiliser une gestion d'état claire pour l'éditeur de documents afin d'assurer une expérience fluide lors des modifications en temps réel.
