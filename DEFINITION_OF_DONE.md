# DEFINITION_OF_DONE.md — Exigences de Validation

Une tâche ou une fonctionnalité est considérée comme **TERMINÉE** uniquement si :

1. [ ] **Compréhension** : Le développeur a compris le fonctionnement du code produit.
2. [ ] **Conformité** : Le code respecte `CONSTRAINTS.md` et `ARCHITECTURE.md`.
3. [ ] **Qualité** : Les exceptions et erreurs d'API/Base de données sont gérées convenablement.
4. [ ] **Tests** : Des tests de base (unitaires backend/frontend) sont écrits et passent avec succès.
5. [ ] **Documentation** : `STATUS.md`, `TASKS.md` et `CHANGELOG.md` ont été mis à jour.
6. [ ] **Propreté** : Aucun fichier temporaire, console.log inutilisé ou code mort n'est laissé.
